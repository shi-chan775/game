# STARFALL

ReactとCanvas APIで作成した、ブラウザーで遊べるオリジナル縦スクロールシューティングです。画面内に収まるレイアウトと、タッチ操作に対応したコントローラーを備えています。

## 起動方法

1. Node.jsをインストールします。
2. プロジェクトのフォルダーで `npm install` を実行します。
3. `npm run dev` を実行し、表示されたURLをブラウザーで開きます。
4. 「START GAME」を押してゲームを開始します。

本番用ファイルは `npm run build` で `dist/` に生成できます。
オンライン協力プレイを含むサーバーは、ビルド後に `npm start` で起動できます（`PORT` 環境変数でポートを指定できます）。本番公開時は、WebSocket接続を含むNode.jsサーバーとして公開してください。開発時は `npm run dev` でフロントエンドとWebSocketサーバーを同時に起動します。

## 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー または WASD |
| 射撃 | スペースキー（押し続けると連射） |

画面内のジョイスティックを倒すと自機が移動し、「FIRE」を押しているあいだ連射します。スマートフォンやタブレットではタッチで操作できます。

## オンライン協力プレイ

スタート画面の「ルームを作成」で5文字のルームコードを発行し、もう一人が別端末でコードを入力して参加します。2人が揃ったらホストが協力プレイを開始します。2人でHPを共有し、合計6回被弾するとゲームオーバーです。ホストの画面でゲームを進行し、相手の入力とゲーム状態をWebSocket経由で同期します。

敵弾または敵機との衝突でHPが1減ります。3回ダメージを受けるとゲームオーバーです。被弾後は短時間の無敵時間があります。「RETRY」で最初から再挑戦できます。

## ゲーム内容

- 通常敵、左右に動く敵、狙いをつけて弾を撃つ強敵が出現します。
- 敵を撃破すると種類に応じて100、200、500点を獲得します。
- 時間が経つにつれて敵の出現頻度や速度、強敵の弾速・連射頻度が上がります。
- 最高スコアはブラウザーのローカルストレージに保存されます。
- 星空、自機・敵機、弾、ヒット・撃破エフェクトはCanvasで描画しています。ゲーム状態・HUD・画面内操作UIはReactで管理します。
